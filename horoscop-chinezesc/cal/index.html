Profilul simbolic

Calul este asociat cu energie, independență, mobilitate, franchețe. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Foc; polaritate Yang. Tema centrală: mișcare, autonomie și exprimare directă.

Expresie dezechilibrată

Pot fi accentuate grabă, instabilitate, nerăbdare. Aceste trăsături nu sunt obligatorii.

Anii Calului

1930, 1942, 1954, 1966, 1978, 1990, 2002, 2014, 2026, 2038. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
