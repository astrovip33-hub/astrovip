Profilul simbolic

Iepureul este asociat cu diplomație, sensibilitate, rafinament, cooperare. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Lemn; polaritate Yin. Tema centrală: relații, armonie și negocierea mediului.

Expresie dezechilibrată

Pot fi accentuate evitare, hipersensibilitate, indecizie. Aceste trăsături nu sunt obligatorii.

Anii Iepureului

1927, 1939, 1951, 1963, 1975, 1987, 1999, 2011, 2023, 2035. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
