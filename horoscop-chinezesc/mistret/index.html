Mistreț în Horoscopul Chinezesc

Profilul simbolic

Mistrețul este asociat cu generozitate, sinceritate, răbdare, sociabilitate. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Apă; polaritate Yin. Tema centrală: cooperare, bunăvoință și bucuria de a construi relații.

Expresie dezechilibrată

Pot fi accentuate naivitate, exces de confort, evitarea limitelor. Aceste trăsături nu sunt obligatorii.

Anii Mistrețului

1935, 1947, 1959, 1971, 1983, 1995, 2007, 2019, 2031, 2043. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
