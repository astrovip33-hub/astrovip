Profilul simbolic

Caprăul este asociat cu sensibilitate, creativitate, cooperare, simț estetic. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Pământ; polaritate Yin. Tema centrală: crearea unui mediu sigur, armonios și expresiv.

Expresie dezechilibrată

Pot fi accentuate ezitare, dependență de climatul relațional, evitare. Aceste trăsături nu sunt obligatorii.

Anii Caprăului

1931, 1943, 1955, 1967, 1979, 1991, 2003, 2015, 2027, 2039. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
