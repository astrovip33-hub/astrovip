Profilul simbolic

Câineul este asociat cu loialitate, principii, protecție, simț al dreptății. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Pământ; polaritate Yang. Tema centrală: încredere, responsabilitate și protejarea valorilor.

Expresie dezechilibrată

Pot fi accentuate îngrijorare, defensivitate, judecată severă. Aceste trăsături nu sunt obligatorii.

Anii Câineului

1934, 1946, 1958, 1970, 1982, 1994, 2006, 2018, 2030, 2042. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
