Profilul simbolic

Cocoșul este asociat cu precizie, organizare, franchețe, vizibilitate. Această descriere este un limbaj simbolic, nu o măsurare a personalității.

Element fix Metal; polaritate Yin. Tema centrală: ordine, standarde și exprimarea clară a poziției.

Expresie dezechilibrată

Pot fi accentuate criticism, perfecționism, rigiditate. Aceste trăsături nu sunt obligatorii.

Anii Cocoșului

1933, 1945, 1957, 1969, 1981, 1993, 2005, 2017, 2029, 2041. Pentru nașteri din ianuarie sau februarie, semnul trebuie verificat față de Anul Nou Chinezesc.
